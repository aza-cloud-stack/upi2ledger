Setup Instructions

  1. Go to the Google Cloud Console and create a new project (or select an existing one).
  2. Enable the Gmail API for your project.
  3. Go to Credentials and create an OAuth 2.0 Client ID (Web application type).
  4. Add http://127.0.0.1:8000/gmail/callback as an authorized redirect URI.
  5. Download the credentials JSON file and save it as data/gmail_credentials.json.
  6. Click Connect Gmail above to authorize access.
